◆ raycast_add_floor()

void raycast_add_floor ( Raycaster *  raycaster,
RaycastTexture *  texture,
const RaycastRect *  rect 
)

Fill a rectangular region of the floor map with a texture.

Registers the texture with the raycaster if it has not been added yet (equivalent to calling raycast_add_texture once), then stamps every cell inside rect with that texture's ID. Cells outside the map bounds are silently ignored.

The texture pointer itself is the only thing needed here — it can be created programmatically with raycast_texture_create() or, in the future, loaded from a file with a helper such as raycast_texture_load_file().

Parameters
raycasterThe raycaster instance.
textureTexture to use for the floor in this region.
rectMap-space rectangle to fill (x/y/w/h in tile units).

Cast a ray from a point at a given angle and return the distance to the first non-black pixel.

This function simulates raycasting by moving step-by-step from the starting point in the specified direction until it hits a non-black pixel or goes out of bounds. It returns the distance traveled from the starting point to the hit point.

Parameters
raycasterThe Raycaster instance containing the map.
xThe x coordinate of the starting point.
yThe y coordinate of the starting point.
angleThe angle of the ray in degrees.
hitColorPointer to store the color of the hit pixel (if any).
Returns
The distance to the first non-black pixel, or 0 if no hit is found.

Render the Raycaster map with textures to the display.

Renders textured floors and ceilings first (full-screen pre-pass via render_floor_ceiling()), then draws textured wall slices, then composites sprites on top using a per-column Z-buffer. Cells whose floor/ceiling map entry is RAYCAST_EMPTY fall back to background.

Parameters
raycasterThe Raycaster instance to render.
cameraThe camera settings for rendering.
rendererThe SDL_Renderer to use for rendering.
wThe width of the rendering area.
hThe height of the rendering area.
backgroundThe background color to use for empty spaces.

Move a sprite along its current direction vector.

Advances the sprite's world position by (dirX * speed, dirY * speed). No collision checking is performed here — use raycast_collides() and raycast_collides_sprites() before calling this if you need collision.

Parameters

◆ raycast_sprite_set_direction()

float  dirX,
float  dirY 
)

Set the facing direction of a sprite.

The direction vector does not need to be normalised. It is used both by raycast_sprite_move() (the sprite advances along this vector scaled by speed) and by the caller for texture selection (e.g. choosing a front vs. back texture based on dirX/dirY relative to the camera).

Parameters
spriteThe sprite to update.
dirXNew X component of the direction vector.
dirYNew Y component of the direction vector.
