Detailed Description

A billboard sprite placed in world space.

The texture pointer can be swapped freely at any time without affecting the sprite's position or direction — use this to implement animations or directional views (e.g. an enemy texture that changes when they turn around). Pixels with alpha == 0 in the texture are treated as transparent and are not drawn.

Ownership: sprites added via raycast_add_sprite() are owned and freed by the Raycaster. Sprite textures are NOT owned by the sprite; the caller is responsible for their lifetime (e.g. by adding them to the raycaster's texture array via raycast_add_texture() for automatic cleanup).
